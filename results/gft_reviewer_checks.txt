IMPORTANT FLAGS (facts, surfaced explicitly because they qualify the summary verdicts above)

FLAG 1 -- PBMC3k does not score below the threshold 7.
The decision framework as given states the expected pattern is "CRC above 7, PBMC below 7."
As measured here (scanpy.datasets.pbmc3k_processed(), 8 louvain types, X_pca[:, :50]):
  PBMC3k heterogeneity_score (true labels)   = 13.149
  PBMC3k heterogeneity_score (Leiden labels) = 13.477
Both are clearly ABOVE 7, not below. Test A's pass/fail logic as implemented only checks that the
label-free score stays on the SAME side as the label-based score WITHIN each dataset (which it
does: both true and Leiden labels put PBMC above 7, so the internal consistency check reports
"YES"). But the premise that PBMC3k is a below-7 negative control does not hold with this exact
loader/label set. Two honest readings: (a) whatever PBMC benchmark established the "PBMC below 7"
expectation used a different subset, filtering, or PC count than scanpy.datasets.pbmc3k_processed()
with its default 50-D X_pca and 8 louvain classes, or (b) the threshold-7 rule of thumb does not
transfer to this specific, commonly-used PBMC3k loading. Either way, this PBMC3k run is not
functioning as a below-7 negative control, and the "usable" verdict for Test A should be read with
that caveat rather than as confirmation that heterogeneity_score cleanly separates the two
datasets the way the task's framing assumed.

FLAG 2 -- Test B (Leiden) and Test C (K-Means) give OPPOSITE verdicts on GFT vs PCA.
Test B: under Leiden clustering, GFT is clearly worse than PCA at every resolution tested
  (best ARI: PCA=0.8938, GFT=0.5413, a large and consistent gap).
Test C: under K-Means clustering (same 50518 cells, same true labels, k=7), GFT is the BEST
  embedding of the four tested -- better than both plain PCA and Harmony:
  PCA=0.7332  Harmony=0.6898  GFT-on-PCA=0.8658  GFT-on-Harmony=0.8695
This is a direct contradiction if read as a single verdict on "GFT vs PCA structural
compatibility": Test B's decision rule (which was specified in terms of Leiden ARI only) reports
the structural-incompatibility claim SURVIVES, while the K-Means numbers computed in the same run,
on the same data and labels, show GFT outperforming both PCA and Harmony. This is not a numerical
error -- it reflects that Leiden and K-Means impose different structure on an embedding (Leiden
is graph-community-based and sensitive to local neighbourhood density; K-Means is centroid-based
and favors compact, well-separated clusters), and GFT's spectral embedding evidently produces
compact K-Means-friendly clusters while producing a graph structure Leiden partitions poorly
relative to PCA's. The honest conclusion is algorithm-dependent, not a single clean verdict: GFT's
apparent "structural incompatibility" is specific to Leiden clustering on a k=20 cosine graph, not
a general property of the GFT embedding across all common clustering methods.
