DEVIATIONS (implementation choices not covered by the pre-registration; no threshold changed)
================================================================================================
- Per-cell residual and cross-fitted CNV values were not stored by the earlier scripts
  (only per-patient AUROC summaries were saved), so both were recomputed here using the
  same imported primitives and identical parameters (seed=0, thin_pct=10, N_HVG=3000,
  Q_PCA=50, Q_SUB=20, 5-fold CV, CNV window_size=250) as scripts/gse178341_prereg.py and
  scripts/gse178341_posthoc.py. The residual pipeline is non-deterministic only in the
  sense that it depends solely on the seeded RNG and the input data, both unchanged, so
  recomputed values should match the original per-patient AUROCs; this was not
  separately verified cell-for-cell against the stored summary CSVs.
- Pair eligibility (>=30/>=30) was computed on PRE-thinning cell counts, exactly as
  pre-registered. Binomial thinning (applied only to the residual pipeline, not to raw
  cell counts) can leave FEWER than 30 cells per group surviving in a given state for a
  given pair; such pairs are reported with their post-thinning n alongside the
  pre-registered n, and pairs where thinning leaves ZERO cells in either group (AUROC
  undefined) are excluded from H-SM1/H-SM2 and flagged by count above.
- CNV scores are restricted to the same post-thinning surviving cells as the residual,
  for a fair within-pair AUROC comparison -- the same convention
  scripts/gse178341_prereg.py used for its own main AUROC comparisons.
- Where the pre-registration's AND-combined H-SM1 conditions could disagree, this script
  declares H-SM1 'not supported' if either condition fails, as the pre-registration
  states under "What is NOT pre-registered."
