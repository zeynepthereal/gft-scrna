CAVEATS
================================================================================================
- D2's 'noise-normalized effect size' divides by VARIANCE, exactly as specified, not by
  standard deviation -- it is not a standard Cohen's d and should not be read as one.
- D3's Poisson noise floor is a delta-method approximation assuming every gene's
  Poisson noise projects fully into the residual (out-of-subspace) term, which
  overstates the noise floor somewhat since a small fraction of any gene's noise does
  fall inside the top-20 subspace. It uses each gene's OWN mean thinned proportion, not
  a shared dispersion model, and ignores any non-Poisson (over-dispersed) variance.
- All quantities are derived from the same expression matrix as the residual being
  diagnosed; this is an internal mechanism check, not independent validation.
- This diagnostic does not change the B1' verdict (NOT SUPPORTED, 2/6, see
  results/geom_r1_fullgene.txt); it only characterizes why (b) collapsed where it did.
